# Xu-Zhaoyu-A3-GardenToy

# How to play Rain Garden

1. Open the Rain Garden project in Visual Studio and press **F5** to run it.
2. Click inside the game window. Use the **left and right arrow keys** to move the cloud until its raindrops line up with a flower.
3. **Left-click** anywhere in the window to turn that flower cyan.
4. To turn a flower magenta, **hold W and left-click** while the cloud is above it.
5. Move to another flower and repeat to create a colour pattern. Each flower keeps its colour until you water it again.
